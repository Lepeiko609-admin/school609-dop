# Сайт-витрина кружков дополнительного образования — Школа №609

Готовый сайт-витрина, который помогает родителям выбрать кружок для ребёнка. Данные загружаются из Google Таблицы (опционально) или из локального JSON. Сейчас на сайте **113 кружков** — реальные данные из вашего Excel-файла «Дополнительное образование (4) (10).xlsx».

## Файлы в этой папке

| Файл | Назначение |
|------|-----------|
| `school609_dop_template.xlsx` | **Готовый шаблон Google Таблицы** с 113 кружками, шапкой на русском, выпадающими списками и инструкцией внутри. Импортируйте его в Google Sheets. |
| `courses_template.csv` | Та же таблица в формате CSV (если xlsx не подойдёт). |
| `courses.json` | Данные кружков в JSON — используются сайтом напрямую, если Google Sheets не подключён. |
| `README.md` | Этот файл с инструкциями. |

## Что на сайте

- **Каталог 113 кружков** с реальными названиями, преподавателями, расписанием, ценами, кабинетами
- **5 корпусов**: 312, 314, 330, 336А, 341А (центр доп. образования)
- **Логика**: сначала выбор возрастной группы → список кружков с фильтрами
- **Возрастные группы**: Дошкольники (2–7), Младшая школа (7–11), Средняя (11–14), Старшая (14–17), Взрослые (18+), Все возраста
- **Направления**: Спорт, Творчество, Техника, Наука, Социально-гуманитарное
- **Фильтры**: бюджет/платно, корпус, направление, поиск по тексту
- **Карточка кружка**: расписание, преподаватель, кабинет, описание, видео-открытка (VK Видео), кнопка «Записаться на mos.ru»
- **Шрифт Golos** на всём сайте
- **Маркетинговые блоки**: Hero с оффером, статистика, лица педагогов, 4 шага «Как записаться», CTA-полоса

# Шаг 1. Загрузить данные в Google Таблицу

## 1.1. Импорт готового шаблона

1. Откройте https://sheets.google.com (войдите под любым Google-аккаунтом)
2. Создайте новую таблицу: большая кнопка **+ (Пустая таблица)**
3. **Файл → Импорт → Загрузить** → выберите `school609_dop_template.xlsx` (этот файл)
4. В диалоге импорта:
   - «Расположение»: **Заменить текущий лист** (или «Создать новую таблицу»)
   - «Режим импорта»: **Заменить электронную таблицу**
   - «Преобразовать числа и даты»: оставить галочку
   - Нажмите **Импортировать данные**

У вас появится таблица с тремя листами:

- **Кружки** — все 113 кружков с правильными заголовками. Цвет строки подсказывает тип:
  - бирюзовый фон = бюджетный (бесплатно)
  - оранжевый фон = платный
  - сиреневый фон = мероприятие (спектакль/экскурсия)
- **Инструкция** — пояснения ко всем колонкам и значениям (откройте, чтобы знать, как редактировать)
- **Справочник** — все возможные значения для выпадающих списков

## 1.2. Редактирование данных

- Меняйте значения прямо в ячейках. Колонки **Тип, Направление, Корпус, Возрастная группа, Рекомендуемый, Мероприятие, Взрослые** имеют **выпадающие списки** — кликните на ячейку, появится стрелка ▼.
- Добавляйте новые кружки внизу — валидация работает ещё для **200 новых строк** (строки 114–313).
- Удаляйте строки целиком (правый клик → Удалить строку), чтобы не оставлять пустых.
- **НЕ меняйте** названия колонок в строке 1 — по ним сайт находит данные.

## 1.3. Публикация для сайта

1. В таблице: **Файл → Общий доступ → Опубликовать в интернете**
2. Выберите:
   - **Что публиковать**: «Весь документ»
   - **Формат**: **CSV** (это важно! Не «Веб-страница»)
3. Нажмите **Опубликовать** (подтвердите, если Google спросит)
4. Скопируйте ссылку вида:
   ```
   https://docs.google.com/spreadsheets/d/e/2PACX-XXXXXXX/pub?output=csv
   ```
5. **Каждый раз после правок** в таблице — зайдите туда же и нажмите «Опубликовать снова» (или «Перестубликовать»), чтобы ссылка отразила новые данные.

# Шаг 2. Подключить ссылку к сайту

Когда вы разместите сайт на Vercel (см. ниже), добавьте переменную окружения:

1. Vercel → ваш проект → **Settings → Environment Variables**
2. Создайте новую:
   - **Name**: `GOOGLE_SHEETS_CSV_URL`
   - **Value**: ваша ссылка из шага 1.3 (вида `https://docs.google.com/.../pub?output=csv`)
3. **Save**
4. В панели Vercel: **Deployments → ⋮ → Redeploy** (или просто сделайте любой коммит в GitHub)
5. Готово. Сайт читает данные из Google Sheets. **Кеш 5 минут** — после правок в таблице и пере-публикации CSV подождите до 5 минут, увидите изменения.

# Шаг 3. Разместить сайт на Vercel (бесплатно)

## 3.1. Залейте код на GitHub

```bash
cd /home/z/my-project
git init
git add .
git commit -m "Школа 609 — доп. образование"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/school609-dop.git
git push -u origin main
```

Если GitHub нет — создайте бесплатный аккаунт на https://github.com, потом создайте пустой репозиторий `school609-dop`.

## 3.2. Подключите Vercel

1. Зайдите на https://vercel.com, авторизуйтесь через GitHub
2. **Add New Project** → выберите ваш репозиторий
3. Vercel сам определит Next.js — **оставьте все настройки по умолчанию**
4. Нажмите **Deploy**
5. Через 1–2 минуты сайт доступен по адресу вида `school609-dop.vercel.app`

## 3.3. Подключите домен school609dop.ru

В панели Vercel:
1. Откройте проект → **Settings → Domains**
2. Введите `school609dop.ru` → Add
3. Vercel покажет: «Добавьте A-запись → `76.76.21.21`» и «CNAME `www` → `cname.vercel-dns.com`»

В панели reg.ru:
1. Личный кабинет → Домены → school609dop.ru → **DNS / Управление зоной**
2. Если ещё не настроено — переключите DNS на `ns1.reg.ru` / `ns2.reg.ru` (бесплатно)
3. Добавьте записи:
   - **A** `@` → `76.76.21.21`
   - **CNAME** `www` → `cname.vercel-dns.com`
4. Сохраните. DNS обновляется 5 минут – 24 часа (обычно ~30 минут)
5. Готово — сайт открывается на `https://school609dop.ru` с бесплатным SSL от Vercel

## 3.4. Подключите Google Sheets (из шага 2)

После того как сайт задеплоен, добавьте переменную `GOOGLE_SHEETS_CSV_URL` (Шаг 2). Без неё сайт работает на данных из `courses.json`.

# Описание всех колонок Google Таблицы

| Колонка | Что писать | Пример |
|---------|-----------|--------|
| ID | Уникальный ID. Не меняйте для существующих. | `341А-1` |
| **Название** | Полное название кружка. Обязательно. | `Акробатика` |
| **Короткое описание** | 1-2 предложения, до 140 символов. | `Конструируем и программируем умных роботов. 7–11 лет.` |
| Описание | Полный текст для детальной страницы. | `Программа направлена на развитие…` |
| **Тип** | Выпадающий список. | `budget` (бесплатно) или `paid` (платно) |
| **Направление (ключ)** | Выпадающий список. Для иконки и фильтра. | `sport` / `creative` / `tech` / `science` / `social` |
| Направленность (текст) | Полное направление. | `Физкультурно-спортивная` |
| **Корпус** | Выпадающий список. | `312` / `314` / `330` / `336А` / `341А` |
| Возраст от | Минимальный возраст (число). | `7` |
| Возраст до | Максимальный возраст (число). | `11` |
| **Возраст (текст)** | Подпись возраста для карточки. | `7–11 лет`, `3–5 лет`, `18+` |
| **Возрастная группа** | Выпадающий список. Группировка на главной. | `preschool` / `primary` / `middle` / `high` / `adult` / `all` |
| **Преподаватель** | ФИО педагога. Несколько через запятую. | `Бобина Т.И.` |
| Регалии | Опыт, категория, награды. | `Мастер спорта, 10 лет опыта` |
| Фото преподавателя (URL) | Прямая ссылка на фото. | `https://…/photo.jpg` |
| **Расписание** | Дни и время. Несколько групп через `\|`. | `[4–7 лет] Вт 10.30-11.00; Пт 10.00-10.30` |
| Видео (URL VK) | Ссылка на VK Видео. | `https://vk.com/video_ext.php?oid=…` |
| **Ссылка на mos.ru** | Полная ссылка записи. | `https://www.mos.ru/pgu/.../?serviceId=2487348` |
| Код на mos.ru | Числовой код. | `2487348` |
| **Стоимость** | Текст цены. Для бюджетных — «Бесплатно». | `Бесплатно`, `4 500 ₽/мес` |
| Кабинет | Где проходят занятия. | `1-й этаж, спортивный зал` |
| Адрес (для мероприятий) | Внешний адрес. | `г. Москва, ул. Варварка` |
| Обложка (URL картинки) | Картинка-обложка, ~16:10. | `https://images.unsplash.com/…` |
| Осталось мест | Число. Если ≤8 — покажем «Осталось N мест». | `5` |
| Рекомендуемый (да/нет) | `да` — кружок в начале списка с меткой ★. | `да` или `нет` |
| Мероприятие (да/нет) | `да` для разовых спектаклей/экскурсий. | `да` или `нет` |
| Взрослые (да/нет) | `да` для кружков 18+. | `да` или `нет` |

Жирным отмечены колонки, которые **обязательно** заполнять. Остальные — по мере наличия.

# Как добавить видео-открытку от преподавателя

1. Снимите видео на телефон/камеру
2. Загрузите на VK: https://vk.com/video → «Загрузить»
3. Откройте видео → **Поделиться → Получить код**
4. Скопируйте URL из атрибута `src` тега `<iframe>`:
   ```
   https://vk.com/video_ext.php?oid=-21661398&id=456239017&hash=abcd1234
   ```
5. Вставьте эту ссылку в колонку **Видео (URL VK)**

Сайт автоматически встроит VK-плеер в карточку кружка.
